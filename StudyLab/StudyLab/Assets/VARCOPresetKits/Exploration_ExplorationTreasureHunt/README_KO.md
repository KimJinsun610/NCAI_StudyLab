# VARCO 프리셋 키트

- 프리셋: ExplorationTreasureHunt
- 장르: Exploration
- 사용 방법: `Parts` 폴더 안의 역할별 프리팹을 같은 역할 이름으로 교체한 뒤 해당 프리셋 자동 제작 메뉴를 실행합니다.
- 제작기는 이 폴더의 실제 역할 프리팹을 먼저 사용하고, 비어 있는 역할만 기존 자동 에셋 인식으로 보완합니다.
- `_SLOT_PLACEHOLDER`가 붙은 파일은 안내용이며 자동 제작 후보에서 제외됩니다.

## 역할 슬롯
- 실제 교체 이름 `01_Player.prefab` / 안내 파일 `01_Player_SLOT_PLACEHOLDER.prefab`: Player
- 실제 교체 이름 `04_ItemPickup.prefab` / 안내 파일 `04_ItemPickup_SLOT_PLACEHOLDER.prefab`: ItemPickup
- 실제 교체 이름 `05_HealthPickup.prefab` / 안내 파일 `05_HealthPickup_SLOT_PLACEHOLDER.prefab`: HealthPickup
- 실제 교체 이름 `06_Goal.prefab` / 안내 파일 `06_Goal_SLOT_PLACEHOLDER.prefab`: Goal
- 실제 교체 이름 `12_Checkpoint.prefab` / 안내 파일 `12_Checkpoint_SLOT_PLACEHOLDER.prefab`: Checkpoint
- 실제 교체 이름 `13_ArenaCover.prefab` / 안내 파일 `13_ArenaCover_SLOT_PLACEHOLDER.prefab`: ArenaCover
